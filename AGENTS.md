# Shotmark

Shotmark (Кадр) is a build-free Chromium Manifest V3 extension for tab screenshots, annotation and local OCR. Load the directory from `chrome://extensions` in Developer mode. Check modified scripts with `node --check <file>` and run the browser suite with `npm test`.

Commit finished changes after the tests pass. Push only when explicitly requested.
