# Verified pitfalls

- **OCR failed before initialization.** The browser ESM build did not expose `createWorker` as a named export. Load the packaged classic browser bundle before the editor and use its `Tesseract` export. Verified by recognizing Russian and English in Chromium while offline.
- **An image can display but its original pixels may be unreadable.** Chromium taints the canvas when a cross-origin image was loaded without CORS. For a top-level image, fall back to its visible tab rectangle. Verified with an image from a second local origin.
- **Recognition can expose stale text after a redaction.** Treat every image edit as a new OCR revision. Clear the previous result and discard an in-flight response if a newer edit has been rendered. Verified OCR omits content covered by a solid mask.
- **The desktop test saved a PNG under its blob ID.** The DevTools download override bypassed Chromium's usual filename handling. Set the download directory in the test profile and use default download behavior. Verified the completed file uses the editor's suggested name and the popup closes after completion.
- **A viewer can show a second copy of the same image above the page.** Rank visible matches by their screen position and mount the text layer within the active dialog. Align with the painted image rectangle so that `object-fit: contain` padding does not move the recognized words. Verified with duplicate images, a native modal, zoom, translation, and single-character selection in Chromium.
- **Signed-out Disk navigation redirects to Yandex Passport.** A Disk-only host permission leaves the Passport tab URL unavailable to the extension. After the helper tab has settled, use the editor notification to open the official sign-in window. Keep the editor open for retries. Verified the live signed-out redirect and official Passport window in an isolated profile.
- **The browser suite failed before opening Chromium.** Node.js rejects copying a directory into one of its own subdirectories, even when a filter excludes the destination. Copy the eligible top-level entries individually into the test extension directory. Verified with `npm test` from the repository root.
